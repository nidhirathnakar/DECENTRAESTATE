## 🚀 HOW TO START (Copy & Paste)

### Step 1: Install Dependencies (5 minutes)
```bash
cd c:\Users\NIDHI\Desktop\projects\blockchain project
npm install
```

### Step 2: Start 4 Terminals

**Terminal 1 - Blockchain (Keep Running)**
```bash
npx hardhat node
```
Expected: `Started HTTP and WebSocket JSON-RPC server at http://127.0.0.1:8545/`

**Terminal 2 - Deploy Contracts**
```bash
npx hardhat run scripts/deploy.js --network localhost
```
Expected: Shows contract addresses

**Terminal 3 - Backend API (Keep Running)**
```bash
node backend/server.js
```
Expected: `Backend server running on http://localhost:3001`

**Terminal 4 - React Frontend**
```bash
cd frontend
npm install  # First time only
npm start
```
Expected: Browser opens at `http://localhost:3000`

### Step 3: Use the Application
1. Click "🦊 Connect MetaMask" button
2. Select account and connect
3. Register a property
4. Create a transaction
5. Test fraud detection
